# AI-Based Question Set Evaluation System

## 1. Project Overview

This project aims to develop an AI-based web application that helps teachers evaluate examination question papers based on course learning outcomes and question types.

## 2. Project Objectives

1. To develop a user-friendly website for teachers.
2. To collect course information and learning outcomes.
3. To classify questions as mathematical, analytical, or theoretical using AI.
4. To evaluate question alignment with CLOs.
5. To compare actual question distribution with the teacher's target distribution.
6. To generate an evaluation report with recommendations.

## 3. Functional Requirements

1. Teachers can enter course names.
2. Teachers can provide CLOs and programming objectives.
3. Teachers can specify target question distribution.
4. Teachers can enter examination questions.
5. The system will validate required inputs.
6. The system will analyze questions using AI.
7. The system will generate evaluation reports.
8. The system will save reports in a database.

## 4. Non-Functional Requirements

1. The website should be easy to use.
2. The interface should be responsive.
3. The system should provide clear evaluation results.
4. The system should handle invalid inputs properly.
5. The system should protect submitted information.

## 5. Technologies

Frontend: HTML, CSS, JavaScript

Backend: Python, Flask

AI: Google Gemini API

Database: MongoDB

Development Tool: Visual Studio Code

Version Control: Git and GitHub

## 6. Development Plan

Day 1: Frontend design, input validation, wireframe, and use case diagram.

Day 2: Python Flask backend and frontend-backend communication.

Day 3: Gemini API integration, MongoDB, testing, and final documentation.
